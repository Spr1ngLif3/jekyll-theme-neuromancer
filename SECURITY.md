# Security policy

## Supported versions

Only the latest minor release of `jekyll-theme-neuromancer` receives
security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems (for example an
XSS vector in a layout or in the search script).

Instead, report it privately through
[GitHub Security Advisories](https://github.com/Spr1ngLif3/jekyll-theme-neuromancer/security/advisories/new).
You should receive a response within a week. Once a fix is released, the
advisory will be published with credit to the reporter unless you prefer to
stay anonymous.
